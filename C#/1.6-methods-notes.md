# C# 1.6 - Methods

> **Revision status:** Strong / Recalled

A method is a named block of code that performs a specific operation. Methods help us reuse code, organize code, give meaningful names to operations, reduce duplication, and make code easier to test and maintain.

---

## 1. Method Declaration

```csharp
static int Add(int a, int b)
{
    return a + b;
}

int result = Add(10, 20);
Console.WriteLine(result); // 30
```

The general structure is:

```csharp
access_modifier return_type MethodName(parameters)
{
    // method body
}
```

For example:

```csharp
public int CalculateTotal(int price, int quantity)
{
    return price * quantity;
}
```

A method declaration can include a modifier, return type, method name, parameters, and method body.

---

## 2. Parameters vs Arguments

A **parameter** is a variable defined in the method declaration:

```csharp
static int Add(int a, int b)
```

Here, `a` and `b` are parameters.

An **argument** is the actual value passed when calling the method:

```csharp
Add(10, 20);
```

Here, `10` and `20` are arguments.

```text
Parameter -> what the method expects
Argument  -> what the caller provides
```

---

## 3. Return Values

A method can calculate a value and return it to its caller.

```csharp
static int Multiply(int a, int b)
{
    return a * b;
}

int result = Multiply(5, 4);
Console.WriteLine(result); // 20
```

The return type `int` means the method promises to return an `int`.

`Console.WriteLine()` displays a value; `return` sends a value back to the caller. Therefore, this is invalid:

```csharp
static int Multiply(int a, int b)
{
    Console.WriteLine(a * b);
}
```

The method must return an `int`:

```csharp
static int Multiply(int a, int b)
{
    return a * b;
}
```

---

## 4. `void`

`void` means that a method does not return a value.

```csharp
static void PrintMessage(string message)
{
    Console.WriteLine(message);
}

PrintMessage("Hello");
```

This is invalid because `PrintMessage` returns `void`:

```csharp
int result = PrintMessage("Hello");
```

A `void` method can use `return;` to exit early without returning a value.

```csharp
static void CheckAge(int age)
{
    if (age < 18)
        return;

    Console.WriteLine("Adult");
}
```

---

## 5. Optional Parameters

An optional parameter has a default value.

```csharp
static void PrintUser(string name, int age = 25)
{
    Console.WriteLine($"{name} - {age}");
}

PrintUser("John");     // John - 25
PrintUser("John", 30); // John - 30
```

Required parameters must come before optional parameters:

```csharp
static void Test(int a, int b, int c = 30)
{
}
```

A required parameter cannot appear after an optional parameter.

---

## 6. Named Arguments

Normally, arguments are matched by position:

```csharp
static void CreateUser(string name, int age, string city)
{
    Console.WriteLine($"{name} - {age} - {city}");
}

CreateUser("Rahul", 30, "Hyderabad");
```

Named arguments identify the target parameter explicitly, so their order can differ:

```csharp
CreateUser(
    city: "Hyderabad",
    name: "Rahul",
    age: 30);
```

The output order is determined by the code inside the method, not by the order of named arguments.

```text
Positional argument -> matched by position
Named argument      -> matched by parameter name
```

## 7. Method Overloading

Method overloading means defining multiple methods with the same name but different parameter signatures.

```csharp
static int Add(int a, int b)
{
    return a + b;
}

static int Add(int a, int b, int c)
{
    return a + b + c;
}

Add(10, 20);       // Calls the first method
Add(10, 20, 30);   // Calls the second method
```

Different parameter types or parameter order can also create overloads:

```csharp
static void Print(int x)
{
}

static void Print(string x)
{
}

static void Calculate(int a, double b)
{
}

static void Calculate(double a, int b)
{
}
```

Return type alone is not enough to create an overload. These methods are invalid together because their parameter lists are identical:

```csharp
static int Add(int a, int b)
{
    return a + b;
}

static double Add(int a, int b)
{
    return a + b;
}
```

```text
Overloading = same method name + different parameter signature
```

## 8. `ref`

By default, parameters are passed by value, so the method receives a copy.

```csharp
static void Change(int x)
{
    x = 100;
}

int number = 10;
Change(number);
Console.WriteLine(number); // 10
```

`ref` allows the method to work with the caller's variable itself:

```csharp
static void Change(ref int x)
{
    x = 100;
}

int number = 10;
Change(ref number);
Console.WriteLine(number); // 100
```

The variable must already be initialized before it is passed with `ref`.

```text
ref -> existing variable; the method can read and modify it
```

---

## 9. `out`

`out` also passes a parameter by reference, but the caller does not need to initialize the variable first. The method must assign the `out` parameter before it finishes.

```csharp
static void GetValue(out int number)
{
    number = 100;
}

int x;
GetValue(out x);
Console.WriteLine(x); // 100
```

This is invalid because `number` is never assigned:

```csharp
static void GetValue(out int number)
{
}
```

A common example is `TryParse`:

```csharp
if (int.TryParse("123", out int number))
{
    Console.WriteLine(number); // 123
}
```

`TryParse` returns a `bool` indicating success and provides the converted value through `out`.

```text
out -> the method produces a value through the caller's variable
```

---

## 10. `in`

`in` passes a parameter by reference but makes it read-only inside the method.

```csharp
static void Print(in int number)
{
    Console.WriteLine(number);
}

int x = 10;
Print(in x);
```

The method can read `number`, but cannot modify it:

```csharp
number = 20; // Invalid
```

---

## 11. `ref` vs `out` vs `in`

| Feature | `ref` | `out` | `in` |
| --- | --- | --- | --- |
| Must initialize before call? | Yes | No | Yes |
| Can method read it? | Yes | Not as an incoming value | Yes |
| Can method modify it? | Yes | Yes | No |
| Must method assign it? | No | Yes | No |
| Main purpose | Modify existing variable | Produce a value | Read-only reference |

```text
ref -> existing value, modify it
out -> produce a value
in  -> read only
```

## 12. Expression-Bodied Methods

An expression-bodied method is a shorter syntax for a method containing one expression.

```csharp
static int Add(int a, int b) => a + b;

static int Square(int x) => x * x;

static bool IsAdult(int age) => age >= 18;

static void Print(string message) => Console.WriteLine(message);
```

Use this syntax for short, simple logic. Do not force complicated logic into one expression just to make the code shorter.

---

## 13. Local Functions

A local function is declared inside another method and is accessible only within that containing method.

```csharp
static void ProcessOrder(int price, int quantity)
{
    int CalculateTotal()
    {
        return price * quantity;
    }

    Console.WriteLine(CalculateTotal());
}
```

A local function is useful when helper logic is required by only one method. It can access variables from the containing method, such as `price` and `quantity` above.

## 14. Complete Example

```csharp
class Order
{
    static decimal CalculateFinalPrice(
        decimal price,
        decimal discount = 0)
    {
        return price - (price * discount / 100);
    }

    static void PrintOrder(string name, decimal price)
    {
        Console.WriteLine($"{name}: {price}");
    }

    static void Main()
    {
        decimal finalPrice = CalculateFinalPrice(
            price: 1000,
            discount: 10);

        PrintOrder(
            name: "Laptop",
            price: finalPrice);
    }
}
```

Flow:

```text
CalculateFinalPrice()
        -> calculate discount
        -> return final price
        -> PrintOrder()
        -> display result
```

## Interview Cheat Sheet

### Parameter vs Argument

```text
Parameter -> variable in method declaration
Argument  -> actual value passed during method call
```

### `ref`, `out`, and `in`

```text
ref -> existing variable; read and modify it
out -> variable does not need an initial value; method must assign it
in  -> passed by reference; read-only inside the method
```

### Overloading

```text
Same method name + different parameter signature
Return type alone cannot overload a method.
```

### Other key points

```text
void                   -> method does not return a value
Optional parameter     -> uses a default value when omitted
Named argument         -> matches an argument by parameter name
Expression-bodied      -> concise syntax for a single expression
Local function         -> helper function scoped to its containing method
```
