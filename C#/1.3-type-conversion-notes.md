# 🟦 C# 1.3 — Type Conversion

> **Revision status:** 📝 Not started

Type conversion changes a value from one type to another. C# supports automatic conversions, explicit casts, parsing, general conversion methods, and runtime type checks.

---

## 🔄 1. Implicit Conversion

C# automatically converts the source type when the conversion is allowed.

```csharp
int a = 100;
double b = a;
```

`int` to `double` is an **implicit conversion**.

### 💡 Remember

> **Implicit = C# performs the conversion automatically.**

---

## 🎯 2. Explicit Conversion and Casting

When C# cannot automatically perform a conversion, we explicitly tell it to convert.

```csharp
double a = 100.9;
int b = (int)a;
```

Result:

```text
b = 100
```

The decimal part is discarded.

### 💡 Remember

> **Explicit = we tell C# to perform the conversion.**

---

## 🧱 3. Casting

Casting uses syntax such as `(int)value` to convert an existing value or object to a compatible type.

```csharp
double value = 100.5;

int number = (int)value;
```

A cast works for compatible conversions, but it does not parse numeric text:

```csharp
string value = "100";

int number = (int)value; // InvalidCastException at runtime
```

---

## 🔢 4. `Parse`

`Parse` converts a string containing valid data into the target type.

```csharp
string value = "123";

int number = int.Parse(value);
```

Result:

```text
123
```

If the string is not valid, parsing throws a `FormatException`:

```csharp
int.Parse("hello"); // FormatException
```

### 💡 Remember

> **`Parse` expects valid text and throws an exception when it cannot parse it.**

---

## ✅ 5. `TryParse`

`TryParse` attempts the conversion without throwing an exception for invalid input.

```csharp
string value = "123";

bool success = int.TryParse(value, out int number);
```

Result:

```text
success = true
number = 123
```

For invalid input:

```csharp
string value = "hello";

bool success = int.TryParse(value, out int number);
```

Result:

```text
success = false
number = 0
```

### 💡 Remember

> **`TryParse` returns `true` or `false` instead of throwing for invalid input.**

It is very useful for user input.

---

## 🔧 6. `Convert`

`Convert` provides conversion methods for different types.

```csharp
int a = Convert.ToInt32("100");
double b = Convert.ToDouble("50.5");
```

A useful difference is how `null` is handled:

```csharp
Convert.ToInt32(null); // 0
int.Parse(null);       // ArgumentNullException
```

---

## 🔎 7. `is`

`is` checks whether a value is a particular type.

```csharp
object value = "Hello";

value is string  // true
value is int     // false
```

It can also be used with a type pattern:

```csharp
if (value is string name)
{
    Console.WriteLine(name.Length);
}
```

### 💡 Remember

> **`is` → “Is this object this type?”**

---

## 🛟 8. `as`

`as` attempts a reference-type or nullable conversion.

```csharp
object value = "Hello";

string name = value as string;
```

`name` becomes `"Hello"`.

If the conversion is not possible, `as` returns `null` instead of throwing:

```csharp
object value = 100;

string name = value as string;
```

`name` becomes `null`.

### 💡 Remember

> **`as` → try to give me this object as this type.**

`as` is not used for normal numeric conversion:

```csharp
object value = 100;

int number = value as int; // Error: int is a non-nullable value type
```

---

## ⚖️ Important Differences

### Cast vs Parse

```csharp
(int)value
```

> Cast an existing value or object.

```csharp
int.Parse(value)
```

> Parse text into an integer.

For example:

```csharp
string value = "100";

int.Parse(value);       // Valid
Convert.ToInt32(value); // Valid
(int)value;             // InvalidCastException
```

### `Parse` vs `TryParse`

```text
Parse
→ success = value
→ failure = exception

TryParse
→ success = true + value
→ failure = false
```

### `is` vs `as`

```text
is → checks the type
as → attempts a reference-type or nullable conversion
```

---

## 🧠 Mental Model

```text
Implicit
→ C# converts automatically

Explicit / Cast
→ you tell C# to convert or cast

Parse
→ string → target type

TryParse
→ string → target type safely

Convert
→ general conversion methods

is
→ check the type

as
→ try a reference-type cast; failure gives null
```

### Most important example

```csharp
object value = "100";

value is string            // true

value as string            // "100"

int.Parse((string)value)   // 100

(int)value                 // InvalidCastException
```

> **Casting and parsing are not the same thing.**
