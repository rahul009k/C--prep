# 🟦 C# 1.3 — Operators & Expressions

> **Revision status:** 📝 Not started

Operators perform operations on values. The operand types and operator precedence determine how an expression is evaluated.

---

## ➕ 1. Arithmetic Operators

Arithmetic operators are used for mathematical operations:

```text
+   // addition
-   // subtraction
*   // multiplication
/   // division
%   // remainder
```

Example:

```csharp
int a = 10;
int b = 3;

a + b; // 13
a - b; // 7
a * b; // 30
a / b; // 3
a % b; // 1
```

### Important: operand types matter

The operand types determine how the operation works.

```csharp
10 / 3      // 3: integer division
10.0 / 3    // 3.333...
```

The calculation happens before assignment:

```csharp
double x = 10 / 3;
```

`x` is still `3`, because `10 / 3` is calculated as integer division before the result is assigned to `x`.

---

## ⚖️ 2. Comparison Operators

Comparison operators compare values. The result is always a `bool`.

```text
==   // equal
!=   // not equal
>    // greater than
<    // less than
>=   // greater than or equal
<=   // less than or equal
```

### 💡 Remember

```text
=    // assignment
==   // comparison
```

---

## 🧠 3. Logical Operators

Logical operators combine or reverse Boolean conditions:

```text
&&   // AND
||   // OR
!    // NOT
```

Simple rules:

```text
&& → both must be true
|| → at least one must be true
!  → reverses true/false
```

Example:

```csharp
true && false  // false
true || false  // true
!true          // false
```

### Short-circuiting

With `&&`, if the left side is false, C# does not evaluate the right side because the complete expression cannot be true.

```csharp
user != null && user.IsActive
```

If `user == null`, C# does not evaluate `user.IsActive`.

---

## 📝 4. Assignment Operators

Normal assignment:

```csharp
x = 10;
```

Compound assignment operators are shortcuts:

```csharp
x += 5;  // x = x + 5
x -= 5;  // x = x - 5
x *= 5;  // x = x * 5
x /= 5;  // x = x / 5
x %= 5;  // x = x % 5
```

---

## 🔼 5. Increment and Decrement

These operators increase or decrease a value by `1`:

```csharp
x++;
x--;
```

The important difference is when the value is used.

```text
x++ → use the current value first, then increment
++x → increment first, then use the value
```

Example:

```csharp
int x = 5;

int a = x++;  // a = 5, x = 6
int b = ++x;  // x = 7, b = 7
```

### 💡 Mental model

```text
x++ → use first, increase later
++x → increase first, use later
```

The same distinction applies to `x--` and `--x`.

---

## ❓ 6. Ternary Operator `?:`

The ternary operator is a short form of a simple `if/else` expression.

```csharp
string result = age >= 18 ? "Adult" : "Minor";
```

Pattern:

```text
condition ? value-if-true : value-if-false
```

Example:

```csharp
int x = 10;
string result = x % 2 == 0 ? "Even" : "Odd";
```

---

## 🛟 7. Null-Coalescing Operator `??`

`??` provides a default value when the left side is `null`.

```csharp
string name = null;

string result = name ?? "Guest";
```

Result:

```text
Guest
```

If `name` is not null:

```csharp
string name = "Rahul";

string result = name ?? "Guest";
```

`result` is `"Rahul"`.

### 💡 Mental model

```csharp
a ?? b
```

> Use `a` if it is not null; otherwise use `b`.

---

## 📥 8. Null-Coalescing Assignment `??=`

`??=` assigns a value **only when the variable is null**.

```csharp
string name = null;

name ??= "Guest";
```

Now `name` is `"Guest"`.

If the variable already has a value, it is not changed:

```csharp
string name = "Rahul";

name ??= "Guest";
```

`name` remains `"Rahul"`.

### 💡 Remember

```text
??  → choose a default value
??= → assign a default value if null
```

---

## 🛡️ 9. Null-Conditional Operator `?.`

`?.` safely accesses a member when the object might be null.

Without it:

```csharp
person.Name
```

If `person` is null, this causes a `NullReferenceException`.

With `?.`:

```csharp
person?.Name
```

If `person` is null, the result is `null` instead of throwing an exception.

This works especially well with `??`:

```csharp
string name = person?.Name ?? "Unknown";
```

Meaning:

> Safely get the name; if it is null, use `"Unknown"`.

### 💡 Mental model

```text
?. → safely access
?? → provide a default
```

## 🧮 10. Operator Precedence

When multiple operators appear in one expression, C# uses precedence rules to determine which operation happens first.

Simplified order for the operators covered here:

```text
()
++ --
* / %
+ -
< > <= >=
== !=
&&
||
=, +=, -=, *=, /=, %=, ??=
```

### Important

`&&` happens before `||`.

Therefore:

```csharp
a || b && c
```

means:

```csharp
a || (b && c)
```

It does not mean:

```csharp
(a || b) && c
```

Use parentheses to make the intended order explicit:

```csharp
(10 + 5) * 2
```
