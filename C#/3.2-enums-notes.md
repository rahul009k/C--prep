# C# 3.2 - Enums

> **Revision status:** Strong / Recalled

An enum defines a set of named constants, usually for a variable that should represent one choice from a related set.

```csharp
enum OrderStatus
{
    Pending,
    Confirmed,
    Shipped,
    Delivered
}

OrderStatus status = OrderStatus.Shipped;
```

The name `OrderStatus.Shipped` communicates intent more clearly than an unexplained integer such as `2`.

---

## 1. Underlying Type and Values

An enum's underlying type is `int` by default. Its members receive sequential values starting at zero unless values are specified.

```csharp
enum Role
{
    User = 1,
    Admin = 5,
    Manager = 10
}
```

The underlying type can be another integral type, such as `byte`:

```csharp
enum RoleCode : byte
{
    User = 1,
    Admin = 5
}
```

Choose explicit values when the numeric representation matters, such as when matching a file format or external protocol.

---

## 2. Casting

An enum can be explicitly converted to its underlying numeric type, and an underlying numeric value can be explicitly converted to the enum type.

```csharp
Role role = Role.Admin;
int value = (int)role;

Role anotherRole = (Role)5;
```

`value` is `5`, and `anotherRole` is `Role.Admin`.

A cast does not verify that the numeric value names a declared member:

```csharp
Role unknownRole = (Role)100;
```

This conversion does not automatically throw. `unknownRole` has the underlying value `100`, even though no named `Role` member has that value. Validate values when they come from untrusted input or external data.

---

## 3. `Enum.Parse` and `Enum.TryParse`

Both APIs can convert a string to an enum value. `Enum.Parse` throws an exception when the input cannot be parsed; `Enum.TryParse` reports failure with `false`.

```csharp
Role role = Enum.Parse<Role>("Admin");
```

For input that may be invalid, prefer `TryParse`:

```csharp
if (Enum.TryParse<Role>("Admin", out Role parsedRole))
{
    Console.WriteLine(parsedRole);
}
else
{
    Console.WriteLine("Unknown role");
}
```

The parsing methods can accept numeric strings too, and a successful parse does not always mean the value names a declared member. Use `Enum.IsDefined` when the input must correspond to a declared named value.

```csharp
if (Enum.TryParse<Role>(input, ignoreCase: true, out Role parsed) &&
    Enum.IsDefined(parsed))
{
    // parsed is a declared Role member.
}
```

```text
Parse     -> invalid format/value -> exception
TryParse  -> invalid format/value -> false
IsDefined -> checks whether a value matches a declared enum member
```

## 4. `[Flags]` Enums

A normal enum usually represents one choice. A flags enum represents a combination of independent options. Assign each option a distinct power-of-two value so each uses its own bit.

```csharp
[Flags]
enum Permission
{
    None = 0,
    Read = 1,
    Write = 2,
    Delete = 4
}
```

```text
Read   = 001
Write  = 010
Delete = 100
```

Combine values with the bitwise OR operator (`|`):

```csharp
Permission permissions = Permission.Read | Permission.Write;
```

Check whether a flag is present with `HasFlag`:

```csharp
bool canRead = permissions.HasFlag(Permission.Read); // true
```

Or use a bitwise test:

```csharp
bool canWrite = (permissions & Permission.Write) != 0;
```

`[Flags]` communicates the intended usage and improves enum formatting; the attribute does not itself enforce valid combinations. The powers-of-two values make the combinations unambiguous.

## 5. Quick Memory Sheet

> **Enum = a named set of related constant values.**

```text
Role.Admin       -> meaningful member name
(int)Role.Admin  -> enum to number
(Role)5          -> number to enum; value need not be declared
Enum.Parse       -> string to enum; can throw
Enum.TryParse    -> string to enum; returns success/failure
[Flags]          -> combine independent options with bitwise operations
```

Use `Enum.IsDefined` when a numeric or parsed value must match a declared member. For flags enums, validate allowed bit combinations according to the application's requirements.
