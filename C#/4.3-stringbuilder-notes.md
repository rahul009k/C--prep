# C# 4.3 - StringBuilder

> **Revision status:** Strong / Recalled

`StringBuilder` is a mutable object for building and modifying text. It belongs to the `System.Text` namespace.

```csharp
using System.Text;
```

---

## 1. Why `StringBuilder` Exists

Strings are immutable. An operation that appears to modify a string produces another string instead:

```csharp
string text = "Hello";
text += " World";
```

The original string cannot be changed. Repeatedly building a string this way can create multiple intermediate strings. `StringBuilder` provides a mutable buffer that can be changed repeatedly.

---

## 2. Basic Usage

Append text to a builder, then call `ToString()` to get a string containing its current contents.

```csharp
using System.Text;

var builder = new StringBuilder();
builder.Append("Hello");
builder.Append(" ");
builder.Append("Rahul");

string result = builder.ToString();
Console.WriteLine(result); // Hello Rahul
```

```text
StringBuilder -> mutable buffer -> ToString() -> string
```

---

## 3. `Append`

`Append` adds content to the end of the builder. Values of different types can be appended.

```csharp
var builder = new StringBuilder();
builder.Append("Age: ");
builder.Append(25);

Console.WriteLine(builder.ToString()); // Age: 25
```

---

## 4. `AppendLine`

`AppendLine` adds the supplied text followed by a line terminator.

```csharp
var builder = new StringBuilder();
builder.AppendLine("Hello");
builder.AppendLine("World");

Console.WriteLine(builder.ToString());
```

This is useful when generating multiline text.

---

## 5. `Insert`

`Insert` adds content at a specified zero-based index in the existing contents.

```csharp
var builder = new StringBuilder("Hello World");
builder.Insert(6, "Beautiful ");

Console.WriteLine(builder); // Hello Beautiful World
```

---

## 6. `Remove`

`Remove(startIndex, length)` removes a number of characters beginning at the specified index.

```csharp
var builder = new StringBuilder("Hello World");
builder.Remove(5, 6);

Console.WriteLine(builder); // Hello
```

The second argument is the number of characters to remove, not the ending index.

---

## 7. `ToString`

`ToString()` returns a `string` containing the builder's current contents.

```csharp
var builder = new StringBuilder();
builder.Append("Hello");
builder.Append(" World");

string result = builder.ToString();
```

Use it when a regular string is needed, for example as a return value or to pass text to an API expecting a string.

---

## 8. `Length` and `Capacity`

`StringBuilder` exposes two useful properties:

```csharp
var builder = new StringBuilder();

Console.WriteLine(builder.Length);   // Number of characters currently stored
Console.WriteLine(builder.Capacity); // Current buffer capacity
```

- `Length` is the number of characters currently in the builder.
- `Capacity` is the amount of buffer space available before the builder needs to grow.

Capacity can increase as more text is appended. It may be specified when constructing a builder if the approximate output size is known:

```csharp
var builder = new StringBuilder(capacity: 256);
```

---

## 9. `string` vs `StringBuilder`

A `string` is immutable. Operations that create changed text return new strings.

```csharp
string text = "Hello";
text += " World";
```

A `StringBuilder` is mutable. Its internal contents can be updated by operations such as `Append`, `Insert`, and `Remove`.

```csharp
var builder = new StringBuilder();
builder.Append("Hello");
builder.Append(" World");
```

---

## 10. When to Use `StringBuilder`

A builder is often useful when text is modified repeatedly, especially in a loop or while producing a large output.

```csharp
var builder = new StringBuilder();

for (int number = 1; number <= 10_000; number++)
{
    builder.Append(number);
    builder.Append(',');
}

string result = builder.ToString();
```

Other examples include generating reports or assembling multiline text. Choose based on the workload rather than replacing every string operation automatically.

---

## 11. When a Regular String Is Clearer

For a small, simple construction, interpolation is usually straightforward and avoids unnecessary builder code.

```csharp
string fullName = $"{firstName} {lastName}";
```

A multi-step builder for this case would add complexity without a meaningful benefit.

---

## 12. Performance Mental Model

Avoid the oversimplification that `string` is always slow and `StringBuilder` is always fast. The appropriate choice depends on the amount and pattern of work, and runtimes can optimize simple concatenations.

```text
Simple or few string constructions -> use string or interpolation
Repeated modifications            -> consider StringBuilder
```

---

## 13. Quick Memory Sheet

```text
StringBuilder -> mutable text buffer
Append        -> add to the end
AppendLine    -> add text and a line terminator
Insert        -> add text at an index
Remove        -> remove (startIndex, length) characters
Length        -> number of characters currently stored
Capacity      -> current buffer space before growth
ToString()    -> produce a string from the current contents
```

> **Core rule:** Use `string` for normal, simple string values. Consider `StringBuilder` when building large text or making repeated modifications.
