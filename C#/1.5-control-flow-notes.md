# C# 1.5 - Control Flow

> **Revision status:** Strong / Recalled ✅

Control flow determines which statements execute, how many times they execute, and when execution moves to another part of the program.

---

## 1. `if / else`

Used when execution depends on a condition.

```csharp
if (age >= 18)
{
    Console.WriteLine("Adult");
}
else
{
    Console.WriteLine("Minor");
}
```

In an `if / else if / else` chain, only the **first matching branch** executes.

---

## 2. `switch`

Used when comparing one value against multiple possible cases.

```csharp
switch (day)
{
    case 1:
        Console.WriteLine("Monday");
        break;

    case 2:
        Console.WriteLine("Tuesday");
        break;

    default:
        Console.WriteLine("Unknown");
        break;
}
```

`break` exits the `switch`, not the complete method or program.

---

## 3. `for`

Used for controlled or repeated iteration, especially when an index is useful.

```csharp
for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}
```

Flow:

```text
initialize -> check condition -> execute -> update -> repeat
```

Output:

```text
0
1
2
3
4
```

---

## 4. `while`

The condition is checked **before** the body executes.

```csharp
int i = 1;

while (i <= 5)
{
    Console.WriteLine(i);
    i++;
}
```

If the condition is initially false, the body executes zero times.

---

## 5. `do-while`

The body executes before the condition is checked.

```csharp
int i = 1;

do
{
    Console.WriteLine(i);
    i++;
}
while (i <= 5);
```

Therefore, a `do-while` executes at least once.

```text
while     -> check -> execute
do-while  -> execute -> check
```

---

## 6. `foreach`

Used to process each element of a collection without manually managing an index.

```csharp
int[] numbers = { 10, 20, 30 };

foreach (int number in numbers)
{
    Console.WriteLine(number);
}
```

Use `foreach` when you do not need the index. Use `for` when you need the index or more control over iteration.

---

## 7. `break`

Immediately exits the current loop or `switch`.

```csharp
for (int i = 1; i <= 5; i++)
{
    if (i == 3)
        break;

    Console.WriteLine(i);
}
```

Output:

```text
1
2
```

---

## 8. `continue`

Skips the current iteration and moves to the next iteration.

```csharp
for (int i = 1; i <= 5; i++)
{
    if (i == 3)
        continue;

    Console.WriteLine(i);
}
```

Output:

```text
1
2
4
5
```

---

## 9. `return`

Exits the current method. It does not necessarily terminate the complete program.

```csharp
static void Test(int number)
{
    if (number == 5)
        return;

    Console.WriteLine(number);
}
```

If `Test(5)` is called, the method ends immediately.

A method can also return a value:

```csharp
static int Add(int a, int b)
{
    return a + b;
}
```

---

## 10. `goto`

Jumps to a labeled statement.

```csharp
int i = 1;

start:

Console.WriteLine(i);
i++;

if (i <= 3)
    goto start;
```

Output:

```text
1
2
3
```

`goto` exists in C#, but normal application code generally prefers loops and other control-flow structures because they make the flow easier to understand.

---

## Most Important Difference

```text
break     -> leave the loop or switch
continue  -> skip the current iteration
return    -> leave the current method
```

```text
for       -> useful when an index or more control is needed
foreach   -> process each element
while     -> condition checked before execution
do-while  -> execution happens before condition check
```
