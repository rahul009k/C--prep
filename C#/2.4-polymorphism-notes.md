# C# 2.4 - Polymorphism

> **Revision status:** Strong / Recalled

Polymorphism means that the same common interface or base type can result in different behavior depending on the actual object.

```csharp
Employee employee = new SeniorDeveloper();
employee.Work();
```

The reference type is `Employee`, but the actual object is `SeniorDeveloper`.

---

## 1. Compile-Time Polymorphism

Compile-time polymorphism is usually achieved through method overloading. The compiler chooses the method based on the arguments and parameter signature.

```csharp
class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }

    public int Add(int a, int b, int c)
    {
        return a + b + c;
    }
}
```

These are different overloads:

```text
Add(int, int)
Add(int, int, int)
```

```text
Compile time
     -> overloading
     -> different parameter signatures
     -> compiler chooses the method
```

---

## 2. Runtime Polymorphism

Runtime polymorphism is achieved through inheritance with `virtual` and `override`.

```csharp
class Animal
{
    public virtual void MakeSound()
    {
        Console.WriteLine("Animal");
    }
}

class Dog : Animal
{
    public override void MakeSound()
    {
        Console.WriteLine("Dog");
    }
}

Animal animal = new Dog();
animal.MakeSound(); // Dog
```

The actual derived object determines which implementation runs.

```text
Base reference
      -> actual derived object
      -> virtual + override
      -> runtime selects derived implementation
```

---

## 3. Method Overloading

Method overloading means using the same method name with different parameter signatures.

```csharp
class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }

    public int Add(int a, int b, int c)
    {
        return a + b + c;
    }

    public double Add(double a, double b)
    {
        return a + b;
    }
}
```

The signatures differ by the number or types of parameters:

```text
Add(int, int)
Add(int, int, int)
Add(double, double)
```

Return type alone cannot create an overload:

```csharp
int Add(int a, int b)
{
    return a + b;
}

// Invalid with the method above:
double Add(int a, int b)
{
    return a + b;
}
```

---

## 4. Method Overriding

Method overriding occurs when a derived class provides a new implementation of a virtual base-class method.

```csharp
class Animal
{
    public virtual void MakeSound()
    {
        Console.WriteLine("Animal");
    }
}

class Dog : Animal
{
    public override void MakeSound()
    {
        Console.WriteLine("Dog");
    }
}
```

The base method must be marked `virtual`, and the derived implementation must be marked `override`.

---

## 5. Virtual Dispatch

Virtual dispatch is the runtime mechanism that selects which overridden implementation executes.

```csharp
Animal animal = new Dog();
animal.MakeSound(); // Dog
```

```text
Reference type -> Animal
Actual object  -> Dog
                     -> Dog.MakeSound()
```

The reference type determines whether the method call is valid and whether the method participates in virtual dispatch. The actual object's type determines which override runs.

---

## 6. Base-Class References

A derived object can be referenced using its base type because the derived type is also a base type instance.

```csharp
Animal animal = new Dog();
```

```text
Dog IS-A Animal
```

This lets common code work with the base type:

```csharp
static void MakeSound(Animal animal)
{
    animal.MakeSound();
}
```

Different derived objects can provide different implementations:

```csharp
class Cat : Animal
{
    public override void MakeSound()
    {
        Console.WriteLine("Cat");
    }
}

MakeSound(new Dog());
MakeSound(new Cat());
```

The same `MakeSound` method works with both derived types.

```text
Animal
  |-- Dog
  |-- Cat
```

---

## Most Important Comparison

```text
Compile-time polymorphism
        -> method overloading
        -> compiler chooses based on signature and arguments

Runtime polymorphism
        -> virtual + override
        -> runtime selects an override based on the actual object
```

---

## Key Interview Answer

> Polymorphism allows code to work with a common type while different implementations provide different behavior.

---

## Final Revision

```text
Overloading -> same method name, different parameter signatures
Overriding  -> derived implementation of a virtual base method
Virtual dispatch -> runtime chooses the override
Base reference  -> base type referring to a derived object
```
