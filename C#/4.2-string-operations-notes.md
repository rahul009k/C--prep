# C# 4.2 - String Operations

> **Revision status:** Strong / Recalled

String operations let you inspect text, check its contents, create transformed strings, and convert between a string and collections of strings. Since strings are immutable, operations that produce changed text return a new string.

---

## 1. `Length`

`Length` returns the number of characters in a string. It is a property, not a method.

```csharp
string text = "Hello";

Console.WriteLine(text.Length); // 5
```

```csharp
text.Length   // Correct
// text.Length() // Incorrect: Length is not a method.
```

---

## 2. `Contains`

`Contains` checks whether a string contains the specified text and returns a `bool`.

```csharp
string text = "Hello World";
bool result = text.Contains("World");

Console.WriteLine(result); // True
```

```text
Contains -> true or false
```

---

## 3. `StartsWith` and `EndsWith`

`StartsWith` checks the beginning of a string. `EndsWith` checks its ending.

```csharp
string text = "Hello World";
string fileName = "report.pdf";

Console.WriteLine(text.StartsWith("Hello")); // True
Console.WriteLine(fileName.EndsWith(".pdf")); // True
```

These are useful for checking prefixes and suffixes, such as URL schemes or file extensions. When case sensitivity or culture matters, choose an overload with an explicit `StringComparison` value.

---

## 4. `Substring`

`Substring` extracts part of a string and returns a new string.

```csharp
string text = "Hello World";

string rest = text.Substring(6);    // "World"
string greeting = text.Substring(0, 5); // "Hello"
```

In `Substring(startIndex, length)`, the second argument is a **length**, not an ending index. `Substring(0, 5)` returns the five characters at indexes 0 through 4.

---

## 5. `Replace`

`Replace` returns a new string with matching content replaced. It does not change the original string.

```csharp
string text = "Hello World";
string result = text.Replace("World", "Rahul");

Console.WriteLine(text);   // Hello World
Console.WriteLine(result); // Hello Rahul
```

---

## 6. `Split`

`Split` divides a string into an array of strings using a separator.

```csharp
string input = "C#,Java,Python";
string[] languages = input.Split(',');

Console.WriteLine(languages[0]); // C#
Console.WriteLine(languages[1]); // Java
Console.WriteLine(languages[2]); // Python
```

The return type is `string[]`. This is commonly used when processing delimited input.

---

## 7. `Join`

`string.Join` combines strings using a separator and returns one string.

```csharp
string[] names = { "Rahul", "John", "David" };
string result = string.Join(",", names);

Console.WriteLine(result); // Rahul,John,David
```

```text
Split: "A,B,C"       -> ["A", "B", "C"]
Join:  ["A", "B", "C"] -> "A,B,C"
```

---

## 8. `Trim`

`Trim` returns a string with whitespace removed from the beginning and end. It does not remove whitespace from the middle.

```csharp
string text = "  Hello   World  ";
string result = text.Trim();

Console.WriteLine(result); // Hello   World
```

Related methods remove whitespace from one side only:

```csharp
text.Trim();       // Beginning and end
text.TrimStart();  // Beginning
text.TrimEnd();    // End
```

---

## 9. `IndexOf`

`IndexOf` returns the zero-based index of the first occurrence of a character or substring. If it is not found, it returns `-1`.

```csharp
string text = "Hello World";

int found = text.IndexOf("World"); // 6
int missing = text.IndexOf("XYZ"); // -1
```

Always account for `-1` when using the result as an index.

---

## 10. `LastIndexOf`

`LastIndexOf` returns the zero-based index of the last occurrence of a character or substring. It returns `-1` when no occurrence is found.

```csharp
string text = "Hello Hello";
int index = text.LastIndexOf("Hello"); // 6
```

Use it when you need the final occurrence rather than the first.

---

## 11. String Comparison

String equality with `==` is case-sensitive:

```csharp
string first = "hello";
string second = "HELLO";

Console.WriteLine(first == second); // False
```

For an explicit case-insensitive comparison, use an overload that accepts `StringComparison`:

```csharp
bool same = first.Equals(second, StringComparison.OrdinalIgnoreCase);
Console.WriteLine(same); // True
```

Comparison behavior can depend on case and culture requirements. Choose the comparison mode explicitly when those details matter. `StringComparison.OrdinalIgnoreCase` performs a case-insensitive ordinal comparison.


## Common Mistakes

- `Length` is a property: use `text.Length`, not `text.Length()`.
- `Replace`, `Substring`, and `Trim` return results; they do not modify the original string.
- The second argument to `Substring(startIndex, length)` is a length, not an end index.
- `IndexOf` and `LastIndexOf` can return `-1` when there is no match.
- `Contains` returns a `bool`, not the matching text.
- `Trim` removes whitespace only from the beginning and end, not from between words.
- Use an explicit `StringComparison` when comparison rules need to be clear.
