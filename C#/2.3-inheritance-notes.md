# C# 2.3 - Inheritance

> **Revision status:** Strong / Recalled

Inheritance allows a derived class to reuse and extend members of a base class.

---

## 1. What Is Inheritance?

```csharp
class Vehicle
{
    public void Start()
    {
        Console.WriteLine("Vehicle started");
    }
}

class Car : Vehicle
{
    public void Drive()
    {
        Console.WriteLine("Car driving");
    }
}

Car car = new Car();
car.Start(); // Inherited member
car.Drive(); // Car's own member
```

`Car` is a `Vehicle`, so it can use accessible members inherited from `Vehicle`.

```text
Vehicle
   ^
  Car
```

The `:` indicates inheritance.

---

## 2. Base Class and Derived Class

```csharp
class Vehicle
{
}

class Car : Vehicle
{
}
```

```text
Vehicle -> base or parent class
Car     -> derived or child class
```

A derived class can access the accessible members of its base class. Private members of the base class are not directly accessible in the derived class.

---

## 3. Base-Class References

A base-class reference can refer to an object of a derived class because a `Car` is a `Vehicle`.

```csharp
Vehicle vehicle = new Car();
```

The reference type determines which members are available at compile time:

```csharp
vehicle.Start(); // Available if Vehicle defines Start()
// vehicle.Drive(); // Invalid: Drive is only declared on Car
```

```text
Reference type -> Vehicle
Actual object  -> Car
```

The object is still a `Car`, even though the variable is declared as `Vehicle`.

---

## 4. `virtual` and `override`

`virtual` allows a derived class to provide a different implementation. `override` supplies that derived implementation.

```csharp
class Animal
{
    public virtual void MakeSound()
    {
        Console.WriteLine("Animal");
    }
}

class Dog : Animal
{
    public override void MakeSound()
    {
        Console.WriteLine("Dog");
    }
}

Animal animal = new Dog();
animal.MakeSound(); // Dog
```

The actual object's type is considered at runtime. This is runtime polymorphism.

```text
Animal reference
      -> Dog object
      -> Dog.MakeSound()
```

If the actual object is an `Animal`, the base implementation runs:

```csharp
Animal animal = new Animal();
animal.MakeSound(); // Animal
```

With `virtual` and `override`, the most-derived applicable implementation for the actual object runs.

---

## 5. `new` Method Hiding

`new` does not override a base method. It hides it with another member in the derived class.

```csharp
class Animal
{
    public void MakeSound()
    {
        Console.WriteLine("Animal");
    }
}

class Dog : Animal
{
    public new void MakeSound()
    {
        Console.WriteLine("Dog");
    }
}
```

The reference type determines which method is accessed:

```csharp
Animal animal = new Dog();
animal.MakeSound(); // Animal

Dog dog = new Dog();
dog.MakeSound(); // Dog
```

```text
override -> runtime polymorphism; actual object matters
new      -> method hiding; reference type matters
```

Use `new` when intentionally hiding a base member rather than participating in overriding.

---

## 6. Sealed Classes

A `sealed` class cannot be inherited.

```csharp
sealed class Dog
{
}

// class Puppy : Dog // Invalid: Dog cannot be inherited
// {
// }
```

```text
sealed class -> final class in the inheritance chain
```

---

## 7. Sealed Overrides

A class can be inherited while preventing a particular method from being overridden further.

```csharp
class Animal
{
    public virtual void MakeSound()
    {
        Console.WriteLine("Animal");
    }
}

class Dog : Animal
{
    public sealed override void MakeSound()
    {
        Console.WriteLine("Dog");
    }
}

class Puppy : Dog
{
}
```

`Puppy` can inherit from `Dog`, but it cannot override `MakeSound()` because `Dog` sealed that override.

```text
Animal
   -> virtual MakeSound()
Dog
   -> sealed override MakeSound()
Puppy
   -> cannot override MakeSound()
```

---

## 8. Constructors and Inheritance

Constructors are not inherited. If the base class has a parameterized constructor, the derived constructor can call it with `base(...)`.

```csharp
class Animal
{
    public Animal(string name)
    {
        Console.WriteLine(name);
    }
}

class Dog : Animal
{
    public Dog(string name) : base(name)
    {
        Console.WriteLine("Dog");
    }
}

Dog dog = new Dog("Tommy");
```

`: base(name)` means that the base-class constructor is called with `name`.

A derived constructor must ensure that the base part of the object is initialized. If the base class has no accessible parameterless constructor, the derived constructor must explicitly call an accessible base constructor.

---

## 9. Constructor Execution Order

When a derived object is created, the base constructor runs before the derived constructor.

```csharp
class Animal
{
    public Animal(string name)
    {
        Console.WriteLine("Animal constructor");
    }
}

class Dog : Animal
{
    public Dog(string name) : base(name)
    {
        Console.WriteLine("Dog constructor");
    }
}

Dog dog = new Dog("Tommy");
```

The flow is:

```text
new Dog("Tommy")
       -> Animal(string name)
       -> Dog(string name)
       -> Dog constructor body
```

```text
Base constructor
       -> derived constructor
```

This ensures that the base portion of the object is initialized before the derived portion.

## 10. Important Mental Models

### Inheritance

```text
Derived class IS-A base class

Car IS-A Vehicle
Dog IS-A Animal
```

### `virtual` and `override`

```text
The actual object decides which override runs.
```

### `new`

```text
The reference type decides which hidden method is accessed.
```

### Sealed class

```text
The class cannot be inherited.
```

### Sealed override

```text
The method cannot be overridden further.
```

### `base(...)`

```text
Calls the base constructor.
```

## Quick Comparison

| Feature | Meaning |
| --- | --- |
| `:` | Declares inheritance |
| `virtual` | Allows overriding |
| `override` | Provides a derived implementation |
| `new` | Hides a base member |
| `sealed class` | Prevents inheritance |
| `sealed override` | Prevents further overriding |
| `base(...)` | Calls a base constructor |

## Final Revision

```text
Base class       -> class being inherited from
Derived class    -> class that inherits and extends
virtual          -> allows a derived implementation
override         -> replaces a virtual base implementation
new              -> hides a base member
sealed class     -> cannot be inherited
sealed override  -> cannot be overridden further
base(...)        -> calls the base constructor
```
